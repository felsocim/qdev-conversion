# 🔄 Convertisseur d'unités en Python

Ce projet est un programme Python simple permettant de convertir différentes unités directement depuis le terminal.

## 🚀 Fonctionnalités

* 🔢 Conversion de valeurs entre différentes unités :

  * kilomètres (km) ↔ miles (mi)
  * kilogrammes (kg) ↔ livres (lbs)
  * degrés Celsius (°C) ↔ degrés Fahrenheit (°F)
* 🖥️ Interface interactive en ligne de commande

⚠️ Actuellement, seule la conversion **kilomètres → miles** est implémentée.

## ▶️ Utilisation

1. Cloner le dépôt :

```bash
git clone https://github.com/felsocim/qdev-conversion.git
cd qdev-conversion
```

2. Lancer le programme :

```bash
python conversion.py
```

3. Suivre les instructions affichées dans le terminal :

* Choisir une conversion en entrant le numéro correspondant.
* Saisir la valeur à convertir.

## 🛠️ Exemple d'utilisation

```
Bienvenue dans votre convertisseur d'unités !

Liste des fonctions de conversion :

(0) km en mi
(1) mi en km
(2) kg en lbs
(3) lbs en kg
(4) °C en °F
(5) °F en °C

Votre choix (0-5) ? 0
Valeur à convertir ? 10

10 km = 6.214 mi
```
